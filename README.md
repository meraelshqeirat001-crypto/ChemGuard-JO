# ChemGuard JO

**ChemGuard JO** is a bilingual (Arabic/English), mobile-friendly educational web app about chemical burns and first aid.

## Features
- No email, password, account, or registration.
- Arabic RTL and English LTR interface.
- Immediate first-aid steps and exposure-specific guidance (skin, eyes, inhalation, ingestion).
- Emergency call shortcut for Jordan (911).
- Common mistakes to avoid and emergency warning signs.
- Short interactive knowledge quiz.
- Progressive Web App support with basic offline caching after the first successful load.

## Deploy on GitHub Pages
1. Create a GitHub repository (for example: `ChemGuard-JO`).
2. Upload **all files and folders inside this ZIP** to the repository root. Keep `assets/icon.png` inside the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish, then open the URL shown in the Pages section.

## Suggested GitHub repository Description
Bilingual chemical burn awareness and first aid web app for Jordan. Includes exposure-specific first aid guidance, emergency warning signs, an interactive quiz, and offline-ready PWA support. No login or personal account required.

## Medical safety note
This app is an educational aid, not a diagnostic tool or a substitute for emergency services or professional medical care. Chemical-specific instructions may differ. Follow the product Safety Data Sheet (SDS), poison-center advice, and emergency clinicians. In Jordan, call 911 for emergencies.
